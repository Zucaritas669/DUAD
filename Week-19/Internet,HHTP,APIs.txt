1. Del Cliente al Servidor 💻 → 💻

Explique paso a paso qué ocurre cuando usted escribe www.youtube.com en el navegador hasta que el video aparece en pantalla.
Debe incluir en su explicación:


1.Qué hace el cliente (navegador).
-> El cliente hace un request a un DNS (Domain Name System)



2.Qué papel cumple el DNS.
-> El DNS es el enargado de "traducir" o "interpretar" los domain names a direcciones Y da un response con el IP público


3.Qué ocurre con la dirección IP.
el cliente usa la IP retornada por el DNS para conectarse al servidor



4.Qué hace el servidor.
-> El servidor retorna un response con el request previamente hecho


5.Cómo entra en juego el protocolo HTTP/HTTPS.
El navegador usa la IP para conectarse al servidor, y esa conexión la hace mediante HTTP o HTTPS

1. Descripción general
JSONPlaceholder es una API REST pública y gratuita para pruebas y prototipos.
No requiere autenticación. Simula operaciones CRUD sin modificar datos reales.
URL base: https://jsonplaceholder.typicode.com

2. Solicitudes

 GET - Obtener usuarios
- Método: GET
- Endpoint: /users
- Parámetros: ninguno
- Respuesta: lista de 10 usuarios en formato JSON

POST - Crear usuario
- Método: POST
- Endpoint: /users
- Cuerpo:
  {
    "name": "Shalston López",
    "email": "shalston97@gmail.com",
    "phone": "8434-2271"
  }
- Respuesta: objeto creado con id asignado por el servidor

DELETE - Eliminar usuario
- Método: DELETE
- Endpoint: /users/2
- Parámetros: id del usuario en la URL
- Respuesta: {} 


3. Ejemplo de respuesta JSON (POST)

  "name": "Shalston López",
